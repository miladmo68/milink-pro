# Milink Daily Instagram Story Automation

## Goal
Create **one finished Instagram Story ad every day at 9:00 AM Toronto time** for **Milink.ca**.

The output must be:
- English
- 1080 × 1920 px (9:16)
- visually premium, modern, bold, and scroll-stopping
- clearly different from previous days
- based on real Milink services, portfolio examples, contact details, and branding
- suitable for posting directly to Instagram Stories

---

## Master Prompt

Create one finished Instagram Story ad for **Milink.ca** in English, sized for **1080×1920 (9:16)**.

Before creating it:
1. Review **https://milink.ca** carefully.
2. Identify Milink’s real services, portfolio/examples, contact information, logo, positioning, and any useful sales points.
3. Review publicly available recent examples from **Toronto-area web design agencies, digital agencies, freelancers, and small-business marketing accounts** to identify current visual and messaging patterns.
4. Use competitor research only for inspiration. Do not copy another brand’s design, wording, or artwork.

### Creative rules
Every day must feel meaningfully different from recent Milink stories.

Vary:
- layout
- composition
- typography feel
- visual hierarchy
- background treatment
- colors
- graphic style
- imagery
- messaging angle
- CTA
- content type

Do **not** keep producing the same card layout, same gradient, same phone mockup, same headline structure, or the same color palette repeatedly.

Rotate between concepts such as:
- weak website vs strong website
- website redesign pain points
- before/after transformation
- mobile responsiveness
- website speed
- SEO / discoverability
- e-commerce
- local-business growth
- portfolio/project showcase
- credibility and trust
- educational web-design tip
- conversion-focused design
- branding
- maintenance/support
- business launch package
- outdated website warning
- landing-page optimization
- local Toronto business angle
- premium modern website angle
- website audit concept
- social proof, only when real proof exists

### Visual direction
The design should feel:
- premium
- sophisticated
- modern
- energetic
- eye-catching
- credible
- agency-quality

Use strong hierarchy so someone can understand the main message in about 2 seconds.

Avoid generic-looking AI ads.
Avoid clutter.
Avoid excessive text.
Avoid fake 3D effects unless they genuinely improve the concept.
Avoid cheesy stock-advertising aesthetics.

### Accuracy rules
Never invent:
- statistics
- client names
- testimonials
- awards
- discounts
- pricing
- project results
- guarantees

Only use claims supported by Milink.ca or other verified information.

### Branding
Use Milink’s real logo from the website when available.
Use real contact information from Milink.ca.
Keep enough brand continuity that the story still feels like Milink, even when the visual style changes substantially.

### Deliverables for each run
Produce:
1. **The finished Instagram Story image** — 1080×1920.
2. **Story headline**.
3. **Short caption** — 1–3 sentences.
4. **CTA**.
5. **One-line creative rationale** explaining what makes today’s concept different from recent ones.

### Anti-repetition check
Before finalizing, compare today’s concept against recent Milink stories available in the thread/project context.

If the composition, color palette, headline structure, imagery, or CTA feels too similar, redesign it before delivering.

The goal is not simply to create a new text variation. The **visual idea itself must change**.

## Review Standard

Before completing each run, ask:

- Would this stop someone from immediately swiping past?
- Does it look professionally art-directed?
- Is it clearly different from yesterday?
- Is the main message understandable instantly?
- Is the CTA obvious?
- Does the design make Milink look more credible?
- Are all claims real and defensible?

If not, improve it before delivering.
