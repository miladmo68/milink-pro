# MIlink Smart Website Intake

Use this as the field contract for the Client Portal brief. Ask only what changes project scope; show conditional questions only when relevant.

## Guided client flow

1. **Business & contact** — business name, industry, contact role, audience, service area.
2. **Project type** — new website, redesign, landing page, e-commerce, booking site, portfolio, content site, custom.
3. **Goals** — leads, sales, bookings, credibility, portfolio, hiring, information; plus success measure.
4. **Pages & content** — single-page vs multi-page, selectable page checklist, add-custom-page field, copy/images ownership.
5. **Features** — contact form, booking, e-commerce, blog, multilingual, member area, CRM, newsletter, analytics, chat, custom feature field.
6. **Brand & visual style** — logo availability, brand guide, colors, typography, reference URLs, things to avoid.
7. **Domain / hosting / existing site** — current URL, domain ownership/status, hosting/CMS access, migration and email needs.
8. **Launch & decision makers** — target date, budget range, primary contact, final approver, compliance requirements.
9. **Files and final notes** — logo, brand guide, photos, copy, product data, documents, other uploads and a free-text requirement.

## Conditional rules

- E-commerce: ask products, payment provider, shipping, tax, inventory and product-photo readiness.
- Booking: ask service types, availability system, deposits and notification rules.
- Multilingual: ask languages, translation owner and preferred default language.
- Redesign: ask what fails today, URL, analytics/SEO to preserve and access owner.
- Domain/hosting: never ask for passwords in a free-text field. Request secure access only after project approval.

## Admin CRM views

- **All registrations**: name, email, registered date, project count, last activity.
- **No project yet**: registered users with zero projects; filter by date and search email/name.
- **Brief submitted**: project type, goals, pages, requested features, domain/hosting state, missing files and target launch.
- **Needs client action**: outstanding project requests, due date and unread messages.
- **Project detail**: brief answers, files, request-file button, message thread, approvals, invoice/e-Transfer state and audit history.

## File request catalog

Logo (SVG/PNG), brand guide, approved colours/fonts, team photos, product photos, written copy, service/pricing list, legal/privacy copy, existing site export, domain/hosting/CMS access, analytics/Search Console/Tag Manager access, reference documents.

Do not request bank credentials, domain passwords or e-Transfer security answers through normal messages.
